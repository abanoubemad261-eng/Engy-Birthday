# Engy's Birthday Invitation ♡

A mobile-friendly, interactive birthday invitation made for Engy by Abanoub.

## Features
Animated love-letter envelope, three-question love quiz, live countdown, six tappable reasons, photo gallery, VIP ticket and animated grand reveal.

## Add real photos
Create a `photos` folder in this repository and upload three photos named `memory-1.jpg`, `memory-2.jpg`, and `memory-3.jpg`. The website displays graceful placeholders until those photos exist. Avoid uploading personal photos to a public repository unless you're comfortable sharing them publicly.

## Deploy on Vercel
Import `abanoubemad261-eng/Engy-Birthday` from GitHub into Vercel. Framework preset: **Other**. Root directory: repository root. No build command or environment variables are needed. Deploy, then share the resulting Vercel URL.

## Event
Tuesday, November 3, 2026 at 6:00 PM — Breadfast By The Pyramids, Giza. The countdown automatically displays a message once the date has passed.

All content is in `index.html` and can be edited directly.
